      Admin · สรุปสำหรับส่ง SMSสร้างอัตโนมัติจากข้อมูลล่าสุด แก้ไขข้อความได้ก่อนคัดลอก

      %RR Ach = Runrate คาดปิดสิ้นเดือน (฿) ÷ เป้าหมายเดือน · เรียงอันดับเฉพาะ Area ที่มีเป้าหมาย · Staff No Sale = พนักงานประเภท Retention (Ret_*) และ Multi (RR_Multi) ที่มีเป้าแต่ยังไม่มียอดเดือนนี้ ตัวเลข % = สัดส่วนต่อพนักงานกลุ่มนี้ใน Area · ตัวย่อ Area: N=North, S=South, E=East, W=West, C=Central, U=Upper, L=Lower (เช่น BMA1 NW = BMA I - North West, UPC LNE = UPC - Lower Northeast) · แคมเปญเรียงตามจำนวนขาย (Qty) · ตัวเลขไม่ขึ้นกับตัวกรองหรือมุมมอง Revenue/QTY

      Admin · อัปเดตข้อมูล

      เมื่อบันทึก ผู้ใช้ทุกคนจะเห็นข้อมูลใหม่ทันที ไฟล์ Excel ถูกประมวลผลในเบราว์เซอร์ของคุณและเข้ารหัสก่อนบันทึก

      Admin · Sale Kit (PowerPoint)

      อัปโหลดไฟล์ใหม่ได้ทุกเมื่อ สไลด์ทั้งหมดในแท็บ Sale Kit จะถูกแทนที่ด้วยไฟล์ใหม่ (ไม่ขึ้นกับชื่อไฟล์) ข้อความ ตาราง กราฟและรูปถูกแปลงในเบราว์เซอร์ของคุณ

      Admin · เชื่อมต่อ GitHub (ตั้งค่าครั้งเดียว)

      กดบันทึกแล้วระบบจะอัปขึ้น GitHub ทันที และเก็บ Token แบบเข้ารหัสด้วยรหัส Admin ไว้ในข้อมูล จึงไม่ต้องตั้งค่าซ้ำ เข้าด้วยรหัส Admin จากเครื่องไหนก็อัปโหลดได้เลย ควรใช้ Fine-grained token ที่ให้สิทธิ์ Contents เฉพาะ repo นี้ และตั้งรหัส Admin ให้เดายาก

      Admin · รหัสผ่าน
